# Project Tracker UI

## Overview
This is a frontend project management app built with React + TypeScript.

It has:
- Kanban Board
- List View
- Timeline View
- Custom Drag & Drop
- Filters with URL sync

## Tech Stack
- React
- TypeScript
- Zustand
- Tailwind CSS
- Vite

## Setup
npm install
npm run dev

## Features
- Custom drag and drop (no library)
- Virtual scrolling (handles 500 tasks)
- Filters saved in URL
- Multiple views
